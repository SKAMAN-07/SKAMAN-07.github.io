# Hive: Multi-Model Deliberation Platform

> Public Web Platform deployed to [https://SKAMAN-07.github.io](https://SKAMAN-07.github.io)

## Overview
Hive is a multi-model consensus deliberation engine where frontier AI models (Architect, Skeptic, Verifier, Synthesizer) debate in real-time, overseen by an executive Arbiter (Gemini) that audits, challenges, and approves publication-grade deliverables.

## Core Features
- **Real-Time Neural Constellation Animation**: Procedural HTML5 Canvas mesh reacting dynamically to model deliberation packets and Arbiter convergence.
- **Zero Host Device Burden**: Computations and model calls run entirely on the visitor's client device via BYOK (Bring-Your-Own-Key) or local desktop daemon bridge.
- **Google Account Authentication**: Google Identity Services (GIS) Sign-In protects against unauthorized bot automation.
- **Anti-Bot Defense & Rate Limiting**: Headless browser detection, client-side cryptographic device fingerprinting, and daily free request quotas prevent spam attacks.
- **Universal File Ingestion**: Ingest and audit source code, PDFs, Word documents, spreadsheets, slides, databases, and images.
- **Publication-Grade Deliverables**: Typeset documents with MathJax equation rendering and PDF export.

## Deployment Instructions
1. Push this folder to your GitHub repository `https://github.com/SKAMAN-07/SKAMAN-07.github.io`

3. Your site will automatically go live at `https://SKAMAN-07.github.io`!
