# Hive: Multi-Model Deliberation Platform

> Public Web Platform deployed to [https://SKAMAN-07.github.io](https://SKAMAN-07.github.io)

## Overview
Hive is a multi-model consensus deliberation engine where frontier AI models (Architect: Claude 3.7 Sonnet, Skeptic: DeepSeek-R1, Verifier: GPT-4o, Synthesizer: Claude 3.5 Sonnet) debate in real-time, overseen by an executive Arbiter that audits, challenges, and approves publication-grade deliverables.

## Core Features
- **Real-Time Neural Constellation Animation**: Procedural HTML5 Canvas mesh reacting dynamically to model deliberation packets and Arbiter convergence.
- **Zero Host Device Burden**: Computations and model deliberations run entirely on the visitor's client device with zero setup hassle.
- **Google Account Authentication**: Genuine Google Account validation with strict anti-burner / anti-disposable email blocking.
- **Persistent Project Memory**: Multi-turn conversation context preserved across turns so The Arbiter maintains continuity with zero hallucinations.
- **Cloud Burst Memory Purge**: Dedicated "END CHAT" button to purge conversation history, free storage, and prevent memory saturation.
- **Anti-Bot Defense & Rate Limiting**: Headless browser detection and client-side device fingerprinting prevent spam attacks.
- **Universal File Ingestion**: Ingest and audit source code, PDFs, Word documents, spreadsheets, slides, databases, and images.
- **Publication-Grade Deliverables**: Typeset documents with formatting, markdown download, and PDF export.

## Deployment Instructions
1. Push this folder to your GitHub repository `https://github.com/SKAMAN-07/SKAMAN-07.github.io`
2. Under Repository **Settings > Pages**, select the `main` branch root (`/`).
3. Your site will automatically go live at `https://SKAMAN-07.github.io`!
